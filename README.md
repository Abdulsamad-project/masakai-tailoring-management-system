# Masakai Tailoring Business Management System

## Project Title
**Design and Implementation of a Tailoring Business Management System with Backend Integration**

**Case Study:** Masakai Tailoring Service

## Project Overview
The Masakai Tailoring Business Management System is a web-based application designed to support the management of tailoring business operations.

The system aims to improve the organization of customer information, measurement records, clothing orders, and other tailoring-related activities. It provides a centralized platform for managing relevant business information and supporting efficient daily operations.

The application was developed as a final-year project in the Department of Computer Science.

## Problem Statement
Traditional tailoring businesses may rely on paper records and manual processes to manage customer details, clothing measurements, orders, and payments. These methods can make information difficult to retrieve and update.

The Masakai Tailoring Business Management System seeks to address these challenges by providing a computerized platform for managing tailoring business information.

## Project Objectives
The objectives of the project are to:

1. Design and implement a web-based tailoring business management system.
2. Provide facilities for organizing customer records and measurement information.
3. Support the management and tracking of tailoring orders.
4. Integrate a backend with a database for storing and retrieving information.
5. Improve the organization and accessibility of tailoring business records.

## Installation and Setup

Follow these steps to run the project locally.

### Step 1: Install XAMPP
Download and install XAMPP on your computer.

### Step 2: Copy the Project
Copy the project folder into the `htdocs` directory inside your XAMPP installation.

Example:

`C:\xampp\htdocs\masakai`

The folder name may differ depending on the downloaded project.

### Step 3: Start the Local Server
Open the XAMPP Control Panel and start:

- Apache
- MySQL

### Step 4: Create the Database
1. Open phpMyAdmin in your browser.
2. Create the database required by the application.
3. Import the project's SQL database file if one is included.
4. Configure the database connection settings in the appropriate PHP configuration file.

**Note:** Use the actual database name and configuration settings specified in the project files.

### Step 5: Run the Application
Open your browser and visit:

`http://localhost/masakai/`

If your project uses a different folder name or entry point, adjust the address accordingly.
